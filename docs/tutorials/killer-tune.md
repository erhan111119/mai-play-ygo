# 杀调（杀手级调整曲）教程摘要（用户原文的机制/线路摘录）

> 收录：2026-10-05。原文目录：旋钮手限一后的补救 / 核心玩法 / 本家相同的发动条件 / 对手回合加速同调 /
> 提示员·旋钮手+3星·混音手+3星·混音手+1星 四条 combo（含"吃锁"变体）。

## 零、旋钮手限一后的补救

构筑投入「苍之深渊 渊眼白龙」：手牌发动把「旋钮手」或「效果遮蒙者」加入手卡来展开。

## 一、核心玩法

* 主卡组所有本家怪兽 + 额外 4 星同调调整「音轨制作人」都有**效果外文本**：
  "场上的这张卡为素材作同调召唤的场合，**手卡 1 只调整**也能作为同调素材" → 所以打法就是
  **通召 A 检索 B，用场上的 A + 手卡的 B 同调召唤 C**。（效果外文本，被无效也能用。）
* 因为是"只用 2 只调整出本家同调"，泛用同调怪大多用不了。

## 二、本家相同的发动条件

主卡组本家 + 音轨制作人的**②效果**共同条件：**"这张卡作为同调素材送去墓地的场合"** →
两只同时被送去墓地时可以 **C1C2 自排连锁**。各家②效果：

| 卡 | ② 效果 |
|---|---|
| 混音手 | 取对象破坏对方场上 1 只怪兽 |
| 唱片师 | 取对象破坏对方场上 1 张魔陷 |
| **旋钮手** | 二选一：① 对方墓地 1 张回到卡组最下面；② **确认对手全部手卡**，之后从卡组检索 1 张本家魔陷 |
| 提示员 | 从对方卡组顶翻 2 张，**1 张除外、1 张回顶/底**（控顶） |
| 音轨制作人（额外） | 取对象把对方场上 1 张卡**弹回手卡** |
| 削波手 | **随机除外对方额外卡组 1 张**里侧卡 |
| 红印鉴③（场上的康） | 无效并破坏对手发动的效果（除外自己墓地 1 只调整当 cost） |

**看手组合**：旋钮手②（看全部手卡）+ 提示员②（看对手抽牌阶段抽到的那张）= 完整情报
→ 案例 a：看到陨石就第五步前收手；案例 b：看到「禁忌的一滴」就提前检索加速同调；案例 c：看手卡判断对手
卡组（如看到同调士 → 用削波手除外对方额外关键卡）。

## 三、对手回合的加速同调（4 张）

* **再混音手（5 星同调调整）②**：对方回合解放自己 → 从墓地选"同调怪兽以外的 2 只调整"，1 只回手、1 只特召 →
  **之后可以**进行 1 只同调怪兽调整的同调召唤（**不强制**，可以只回收不加速）。
* **削波手**（手卡）：对方主要阶段特召自身 → 之后可以进行 1 只同调怪兽调整的同调召唤（不强制用自身当素材）。
* **速攻魔法「杀手级调整曲同调」**：1 回合可发动最多 2 张；检索 1 张本家卡 +
  可以做 1 只同调怪兽调整的同调召唤（可在**抽牌阶段**发动 → 不吃锁鸟；也能盖放当终端）。
* **B2B（10 星同调调整）③**：1 回合最多 2 次；对手发动怪兽效果时，以 10 星以外自己墓地·除外区 1 只调整为
  对象 → 那只加入手卡或特召 → 之后可以做 1 只同调怪兽的同调召唤。**B2B 在场时自己的调整怪兽同一战斗阶段可攻击 2 次**（斩杀件）。

## 四、"提示员单卡"combo（终场）

NS 提示员 → ① 特召旋钮手 → 3+1 = **音轨制作人**（4 星同调调整）→ C1 墓地旋钮手②（看手 + 检索「同调」）、
C2 音轨制作人 检索**场地「点唱机酒吧」**、C3 墓地提示员②（控顶）→ 发动场地③ 解放音轨制作人 → 特召**唱片师**
→ 唱片师检索**混音手** → 场地① 追加通召混音手 → 混音手检索**唱片师** → 场上 2 星混音手 + 手卡 3 星唱片师 =
**再混音手**（5 星）→ **盖放「同调」**。

**终场：5 星再混音手 + 3 星唱片师 + 盖放「杀手级调整曲同调」。**

对手回合：再混音手② 解放自身 → 特召墓地唱片师 + 回收旋钮手 → 唱片师+旋钮手 = 音轨制作人
（C1 检索提示员 / C2 唱片师检索削波手 / C3 旋钮手② 看手+检索）→ 需要解场时发削波手 → 用场上音轨制作人 +
手卡提示员加速同调 **7 星「锁缚龙 锁镰」**（C1 墓地音轨制作人弹 1 张 / C2 提示员控顶）→ 需要康时
C2 速攻「同调」、C3 锁缚龙康对手 C1 → 之后 7 星锁缚龙 + 3 星唱片师 加速同调 **10 星 B2B** →
B2B 再拉墓地唱片师 + 场上削波手 → 5 星**红印鉴**；第二次拉墓地音轨制作人 + 手卡混音手 → 6 星**响度战争**。

## 五、"提示员单卡吃锁"combo

被「小丑与锁鸟」时：连锁它发动「同调」检索唱片师（不能从卡组拿到手，但**能从墓地回收**）→ 场地① 通召唱片师
→ 唱片师回收墓地旋钮手 → 场地③ 解放唱片师特召混音手 → 混音手回收墓地唱片师 → 混音手+唱片师 = 再混音手 → 结束。
**终场：再混音手 + 音轨制作人 + 手卡旋钮手。**

## 六、"唱片师单卡"combo

NS 唱片师 → 检索旋钮手 → 同调召唤音轨制作人 → C1 旋钮手② / C2 音轨制作人 检索场地 → 场地③ 解放音轨制作人
特召**混音手** → 混音手检索**提示员** → 场地① 追加通召提示员 → 提示员① 特召墓地音轨制作人 →
3 星提示员 + 2 星混音手 = **再混音手** → 墓地提示员② 控顶 → 盖放「同调」。
**终场：再混音手 + 音轨制作人 + 盖放「同调」。**

## 七、"旋钮手 + 任意 3 星调整"两卡 combo（含 8 混音手+3 星同款）

旋钮手①（展示自身+手卡 1 只调整）追加召唤旋钮手 → 旋钮手 + 手卡 3 星 = 音轨制作人 →
C1 旋钮手② / C2 音轨制作人 检索**提示员** → NS 提示员 → ① 特召混音手 → 混音手检索唱片师 →
场上 4 星音轨制作人 + 手卡 3 星唱片师 = **锁缚龙**；场上 3 星提示员 + 2 星混音手 = **再混音手** → 盖放「同调」。
**终场：锁缚龙 + 再混音手 + 盖放「同调」。**
（两卡线自己回合就出锁缚龙 → 再混音手② 不会被对手 C2「墓穴的指名者」无效，因为 C3 能用锁缚龙康掉。）

## 八、"混音手 + 任意 3 星调整"两卡 combo

NS 混音手 → 检索旋钮手 → 旋钮手① 追加召唤 → 旋钮手 + 手卡 3 星 = 音轨制作人 → C1 旋钮手② / C2 音轨制作人 检索场地
→ 场地③ 解放混音手 → **提示员** 加入手卡 → 召唤提示员 → ① 特召唱片师 → 唱片师检索混音手 →
4 星音轨制作人 + 3 星提示员 = **锁缚龙**；3 星唱片师 + 手卡 2 星混音手 = **再混音手** → 盖放「同调」。
**终场：锁缚龙 + 再混音手 + 盖放「同调」。**

## 九、"混音手 + 任意 1 星调整"两卡 combo

NS 混音手 → 检索旋钮手 → 旋钮手① 追加召唤 → 场上 1 星旋钮手 + 2 星混音手 + **手卡 1 星调整**（3 只）= 音轨制作人
（**场上的本家怪当素材时只能用手卡 1 只调整**）→ C1 旋钮手② / C2 音轨制作人 检索场地 → 场地③ 解放混音手 →
提示员 → 提示员① 特召唱片师 → 唱片师检索混音手 → 3 星唱片师 + 手卡 2 星混音手 = 再混音手 → 盖放「同调」。
**终场：提示员 + 再混音手 + 盖放「同调」。**（终场较小，是稀有的牌型。）

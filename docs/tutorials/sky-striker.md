# 闪刀 教程摘要（用户原文的机制/线路摘录）

> 收录：2026-10-05。原文目录：概况 / 实战情况 / 战斗阶段反复变身斩杀 / 绚岚之见神·落胤与圣女·三战之号 /
> 展开说明 / 零衣·露世·大黄蜂·交闪 四条单卡 combo。

## 一、核心：快速凑三魔

* 墓地魔法 ≥3 时，绝大多数「闪刀」魔法有追加效果：抓锚 → 无效后**夺控制权**；交闪 → **多抽 1 张**。
* 「交闪」「抓锚」**没有卡名一回合一次** → 一个回合里能发动不止 1 次交闪；凑齐三魔后每回合交闪能抽 2-3 张。
* 燎里（LINK1）特召时回收墓地 1 张「闪刀」魔法；零露（LINK2）特召时检索 1 张「闪刀」魔法。

## 二、实战判定（都影响实现）

1. **抓锚两张的用法**：第一张**不要夺控制权**（夺了之后主怪兽区有对手的怪兽，第二张开不出来）；
   第二张再夺。或者 C1、C2 两张抓锚一次牛两只。
2. **追加效果以"主效果通过"为前提**（例：烈火再燃没能破坏怪兽 → 追加的炸魔陷不处理）。
3. **唯一的自肃**：连刀（速攻）发动后，直到回合结束自己不是「闪刀姬」怪兽不能从额外卡组特殊召唤
   → 不能 C1 超融合、C2 连刀。
4. **连刀能躲取对象效果**：对手取对象无效我的魔法卡/我的场上怪兽效果时，C2/C3 连刀把那张卡送去墓地
   换成额外卡组的「闪刀姬」→ 对手效果失去对象不处理。（主怪兽区空着才能发。）
5. **追加效果在"效果处理时"判定**：C1 抓锚、C2 连刀把自己送墓 → 处理 C1 时墓地已 3 张（含自身）→ 能夺控制权。
6. 交闪的调度：堆墓后回手（飒天战斗后堆墓 / 卡米丽娅墓地 ≤3 时堆墓，再用燎里回收）、
   零露① 直接检索、系统外滤抽（绚岚之见神等）。

## 三、战斗阶段反复变身斩杀（**第一回合没有战斗阶段，这段只适用于有战阶的回合**）

零衣攻击 → 变身零露 → 零露攻击 → 连刀把零露送墓出燎里（回收连刀）→ 燎里攻击 → 用回收的连刀再变飒天攻击。
换序：先用连刀出零露、不开①直接打 → 零露②解放自己拉零衣+露世并炸 1 → 两小只攻击 → 零衣① 变身再打。
连刀的 +1000 不需求三魔，只要场上/墓地有光和暗的「闪刀姬」各一只（零露② 拉的零衣=暗、露世=光）。

## 四、系统外三张

* **绚岚之见神**：抽 2 丢 1 速攻（凑三魔）；或从卡组·墓地拿「旋风」。
* **落胤与圣女**：炸 1 + 把「烙印龙 白界龙」送墓；EP 时白界龙盖 1 张「烙胤」魔陷。
  先攻可 C2 连锁自己的魔法、炸自己的魔法来凑三魔并 EP 盖回来当阻坑。
* **三战之号**：先攻基本是"盖一张通常陷阱（构筑里放「嗤笑的黑山羊」）"；后攻检索「交闪」补点。

## 五、展开说明（通用）

* 优先做出 LINK2「零露」；做不出就**盖放连刀**，在对方回合 cost 一卡出零露。
* 零露② 拉零衣+露世并炸 1；**尽可能堆墓「双纽闪门」**——墓地②：自己场上有「闪刀」怪兽特召时除外自身，
  做 1 次「闪刀姬」连接召唤（对手回合的加速连接 = 阻抗核心）。
* 用零衣① 解放自己 → 出燎里（回收续航）→ 触发墓地双纽闪门的② → 用燎里+露世连接召唤 LINK2 做康
  （泽克＝除外 / 阿泽莉亚＝炸卡）。
* 也可以盖放「双纽闪门」：① 要求墓地「闪刀姬」怪兽与「闪刀」魔法**各相同数量**回到卡组，
  每 3 张弹 1 张对方的卡（只能双数、至少 4 张才有 1 次弹卡）。

## 六～九、四条单卡 combo（终场按原文）

| 起手 | 线路 | 终场（我方回合结束） |
|---|---|---|
| 零衣 | NS 零衣 → ① 出**零露**（EMZ）→ 零露① 检索交闪并发动（检索**连刀**）→ 连刀把零露送墓出**燎里** → 燎里① 回收墓地的交闪并发动（检索**第二张连刀**）→ 燎里连接召唤**雫空** → **盖放连刀** → EP：雫空② 检索**双纽闪门**并发动①（把 零露+连刀 回卡组） | **雫空 + 盖放连刀 + 墓地双纽闪门** |
| 露世 | NS 露世 → 连接召唤**雫空** → EP：雫空② 检索连刀 → 连刀把雫空送墓出**零露** → 零露① 检索**双纽闪门** → 发动双纽闪门①（雫空+连刀 回卡组） | **零露 + 墓地双纽闪门** |
| 大黄蜂 | 大黄蜂生 token → token 连接召唤**燎里** → 燎里① 回收大黄蜂再发（再生 token）→ 燎里+token = **零露** → 零露① 检索交闪并发动（检索**双纽闪门**）→ 盖放双纽闪门 | **零露 + 盖放双纽闪门** |
| 交闪 | 交闪① 检索**大黄蜂**并发动 → token 连接召唤**燎里** → 燎里① 回收交闪再发（检索**连刀**）→ 连刀把燎里送墓出**零露** → 零露① 检索**第二张交闪**并发动（检索**双纽闪门**）→ 盖放双纽闪门 | **零露 + 盖放双纽闪门** |

→ 用 燎里+露世 连接召唤**泽克**（除外对方 1 只）→ 合计**一炸一除** + 手卡交闪续航。
（露世线同款但少一张交闪续航；大黄蜂/交闪线可先 C1 零露②、C2 双纽闪门① 弹 1 张。）

## 一、为什么投入「蕾祸」小轴

* 传统虫惑魔靠本家 + 「落穴」「洞」陷阱打消耗，**手坑抗性与补点能力有限**；「蕾祸」提供
  **强力动点与补点**（「蕾祸之毬首」伪一卡启动）以及**续航**（蕾祸连接怪每回合都能把场上 1 只
  昆虫·植物族回卡组、自身从墓地自跳）。
* 两个系统的自肃（"只能特殊召唤昆虫族·植物族[·爬虫类族]怪兽"）**互不干扰**；
  但"蕾祸 → 虫惑魔"非常亏卡，所以这套只走**虫惑魔 → 蕾祸**的方向。

## 三、终场（教程口径）

* 转轴线（「特莱恩」/「兰卡」+ 任意陷阱）：
  **「蕾祸之大王鬼牙」＋「塞拉之虫惑魔」＋陷阱「蕾祸大轮首狩舞」＋ 1 张「洞」/「落穴」**（四张阻坑）；
  结束阶段按姬邪眼抽 2。
* 纯蕾祸两卡线（「毬首」+ 任意昆虫·植物族，不占 NS）：
  **「蕾祸之大王鬼牙」＋陷阱「蕾祸大轮首狩舞」＋抽 1**。
* 不做转轴的纯虫惑魔只能做出"本家 R4 + LINK1 + 陷阱"，**没有续航**。

## 四、两条 combo 的步骤（原文）

**A. 「特莱恩」+ 任意陷阱**：NS 特莱恩 → 检索「破洞露蒂亚」→ 特莱恩连 LINK1「塞拉」→
发动破洞露蒂亚（丢 1 张通常陷阱，盖放回合即可开）→ 它变 4 星怪 + **触发塞拉② 从卡组拉虫惑魔**
（丢的陷阱带「洞」/「落穴」字段就拉**蒂奥**并把它盖回来；否则拉**特莱恩/普蒂卡**）→
此时场上 3 只虫惑魔 + 1 张陷阱 → 用"主怪兽区正中央以外"的 2 只连 LINK2「茉莉」→
茉莉② 解放连接区 1 只 → 从卡组拉「毬首」→ 毬首② 检索「矢筈天牛」+「姬邪眼」→ 除外姬邪眼 →
天牛① 让姬邪眼回卡组、自跳 → 毬首+天牛 = LINK2「武者髑髅」→ **天牛② 复活虫惑魔** →
用它连 LINK1「塞拉」→ 武者髑髅① 特召墓地天牛 → 武者髑髅+天牛 = LINK3「御拜神主」→
御拜神主① 检索「大轮首狩舞」→ 场上剩下的虫惑魔连第二只「塞拉」→ 御拜神主+武者髑髅 = LINK5「大王鬼牙」→
结束阶段姬邪眼抽 2。

**B. 「毬首」+ 任意昆虫·植物族（不占 NS）**：毬首送墓自跳 → ② 检索天牛+姬邪眼 → 除外姬邪眼 →
天牛① 让姬邪眼回卡组、自跳 → 毬首+天牛 = 武者髑髅 → 天牛② 复活「毬首」→ 武者髑髅① 特召墓地天牛 →
武者髑髅+天牛 = 御拜神主 → 武者髑髅② 把毬首回卡组、自身自跳 → 御拜神主① 检索大轮首狩舞 →
御拜神主+武者髑髅 = 大王鬼牙 → 结束阶段姬邪眼抽 1。

## 五、执行器现状（`TraptrixRagnaraikaExecutor.cs`，2026-10-05 v1）

* 已做：全部本家**逐张点名**（避免"没点名的卡被通用兜底整只否掉"——升辉月白龙踩过）、
  塞拉②/③ 与特莱恩① 的检索顺序、毬首② 的两段（检索 [天牛, 姬邪眼] + 除外手卡的姬邪眼）、
  天牛①/② 的顺序、茉莉② 拉毬首、御拜神主① 取大轮首狩舞、武者髑髅① 先拉毬首、
  破洞露蒂亚"盖放回合就开"、非三族额外怪的自肃闸门、额外卡组爬升顺序 + 连接素材按族挑。
* 实测（对空白 30 局）：**30–0**，每局 **34.2 次特召 / 33.0 次效果**（是五副商店牌的两三倍），
  首回合场上至少能见到「塞拉」+ 盖着的「洞/落穴」，也能走到「茉莉 → 御拜神主 + 大轮首狩舞」。
* **已修（同一轮）**：
  1. **特莱恩① 第一张要拿「破洞露蒂亚」**（原来把它排最后）——它既是**植物族身体**（茉莉的素材）、
     又是启动件（盖放回合就能开 → 触发塞拉②）。改完之后 **茉莉出场 29/30**、**御拜神主 29/30**、
     **大王鬼牙 20/30**、塞拉 48 次（30 局）——**整条爬升链在跑**。
  2. **武者髑髅① 的复活顺序**：爬升没做完时先拉**天牛**（它② 能复活虫惑魔、凑下一段素材），
     做完御拜神主/大王鬼牙之后才改成拉毬首（教程的续航用法）。
  3. **连接素材按"凑够连接值"挑**（`Util.CanMakeLinkRating`）：大王鬼牙要连接值 5，
     教程的收尾是 **御拜神主(3) + 武者髑髅(2)**；按连接值从大到小取正好两步凑齐。
  4. 「蕾祸」连接怪自跳的代价（回卡组那只）优先送回**已经用过的引擎件**（毬首/天牛）。
* **还差**：这些**都发生在第 3 回合起**（首回合结束的采样点上大王鬼牙仍是 0/30）——
  首回合少的是"最后一次连接召唤的素材/额外召唤机会"，要按线路状态做成计划层
  （现在是固定顺位 + 通用爬升），不是再加一条规则。

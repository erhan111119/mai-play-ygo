## 一、四种调度本家魔法的方法（吃坑后补点也靠这四条）

1. **下级① + 它们各自的②**：下级①＝"解放自己 + 丢 1 张魔法 → 从卡组特召另一只「魔女术」"（二换一，本身亏）；
   亏的卡靠②补：**锻造女巫②**（除外墓地的自己 → 从卡组堆墓 1 张本家卡）、
   **万能杰妮②**（除外墓地的自己和 1 张本家魔法 → **变成那张魔法发动时的效果**）。
   → 锻造② 堆墓目标卡 + 万能杰妮② 复制它 = **复制卡组里任意 1 张本家通常·速攻魔法**的效果
   （锻造② 也能用来堆墓万能杰妮）。
2. **恩底弥翁的侍女 玻璃②**（特召时检索 1 张本家魔陷）：调度范围最大，**能检索场地「魔女的圣夜行」直接发动**
   （万能杰妮② 复制不了场地）→ 绝大多数情况用她拿场地（除非场地本身就是起手件）。
3. **场地「魔女的圣夜行」②**：自己回合为让本家怪兽效果发动而丢手卡的场合，**代替丢弃** →
   从卡组送 1 张本家魔陷进墓。→ 把锻造/万能杰妮/绘画 的①从"亏 1 张魔法"变成"**3 次精准堆墓本家魔陷**"。
4. **融合怪「学童组合」**：自己·对方的主要阶段以及战斗阶段，检索 1 张本家魔法。
   它和代理师傅的融合条件一样，但代理师傅不能直接检索魔法 → **常规先出学童组合拿融合魔法，再用那张融合出代理师傅**。

## 二、慶典（融合是这副牌的赚卡核心）

* 慶典（速攻）＝ 把**自己墓地·除外的魔法师族怪兽**当融合素材回卡组，融合召唤 1 只本家融合怪
  → 所以"堆墓本家怪兽 → 用上面四种方法调度到慶典 → 融合 → 融合怪赚卡"是整副牌的展开思路。
* 三只融合的赚卡点：**代理师傅**（炸卡阻坑 / 从卡组拉本家 / 回收墓地本家魔陷）、
  **学童组合**（每回合检索本家魔法）、**大魔女**（融合召唤时从手卡·卡组拉最多 3 只 7 星以下本家，同属性最多 1 只）。
* 另一张融合件：**赤陶偶（陶俑魔像）②**＝选手卡·场上的怪兽当融合素材。
  → **赤陶偶② + 慶典 + 万能杰妮②复制慶典 = 一回合最多 3 次融合**。

## 三、常见问题

**1. 大魔女的素材（玻璃女巫 + 魔法师族×2）怎么出最赚**：用**锻造女巫② 堆墓「魔女术师傅·玻璃女巫」** →
墓地/除外区就凑齐了 2 个素材，加上被锻造① 拉出的那只怪正好 3 个 → 直接发慶典（或用万能杰妮② 复制被堆墓的慶典）
融合召唤大魔女。（若锻造② 已经堆过别的，就别为了大魔女再补——实战很亏。）

**2. 大魔女① 拉什么**（默认大魔女是慶典出的，慶典已把只带 1 张的下级返回卡组，所以想拉谁就拉谁）。
场上**有场地**时拉这三只：**服装女巫**（7 星，站场即阻坑）+ **赤陶偶**（②和场上大魔女融合出代理师傅）
+ **1 只还没发动过①的本家下级**（它① 用场地堆墓反击陷阱，并特召 **8 星「魔女术师傅·玻璃女巫」**当阻坑）。
因为魔法师族怪兽发动了效果，**代理师傅**把墓地的反击陷阱加入手卡后**盖放**当阻坑。

**3. 手牌 cost 从哪来**（超魔导龙骑士与两个大姐都要丢手牌）：① **代理师傅**回收 1 张本家魔陷（第 1 张 cost）；
② **场地②** 精准堆墓 4 次（第 1 次慶典参与展开、第 2 次反击陷阱「歪曲」当阻坑，后两次留给这回合没发过①的本家魔法）；
③ 那些"墓地②"的卡在自己 EP、场上有本家怪兽时回手（第 2、3 张 cost）。

## 四、起手线：「魔女的圣夜行」/「魔力统辖」/「魔女术的创造」+ 1 cost（19 步）

1. 圣夜行① 检索 **恩底弥翁的侍女 玻璃**，丢 1 张手卡（＝cost）。
2. 侍女玻璃（魔法卡效果发动的回合的自己主要阶段）从手卡自跳 → ②检索**魔女术的创造**。
3. 创造① 检索 **锻造女巫**。（若起手是魔力统辖/创造：用它检索侍女玻璃 → 侍女玻璃检索圣夜行 → 圣夜行检索锻造并丢 1 张）
4. NS 锻造女巫 → ① 解放自己、**堆墓慶典** → 特召 **万能杰妮**。
5. 万能杰妮① 解放自己、**堆墓反击陷阱「歪曲」** → 特召 **陶器女巫**。
6. 陶器① 解放自己、**堆墓永续魔法「小巷」** → 特召 **商标女巫**。
7. **除外商标女巫** → 特召 **毁灭之黑魔术师** → ①检索**蒂迈欧之眼光**。
8. 毁灭之黑魔术师 + 侍女玻璃 → 连接召唤 **I：P百变莱娜**。
9. 发动蒂迈欧之眼光 → 拉出 **超魔导龙骑士-真红眼龙骑士**（护航 + 逼陨）。
10. 墓地锻造② 堆墓 **玻璃女巫**。
11. 墓地万能杰妮② 复制墓地的慶典 → 把 除外区的商标女巫/万能杰妮 + 墓地的玻璃女巫 当素材 → 融合 **大魔女**。
12. 大魔女① → 特召 **服装女巫 + 赤陶偶 + 绘画女巫**。
13. 赤陶偶② → 它和大魔女融合 → **学童组合**（学徒）。
14. 学童组合① → 检索 **慶典**。
15. 发慶典 → 墓地的赤陶偶 + 侍女玻璃 当素材 → 融合 **代理师傅**。
16. C1 绘画女巫① 解放自己、堆墓**怠工** → 特召 **恩底弥翁的侍女 杰妮**；C2 **代理师傅**回收墓地的**歪曲**。
17. 盖放反击陷阱 **歪曲**，回合结束。
18. EP：墓地**小巷** 表侧放置回魔陷区；墓地**怠工** 回手；**学童组合** 把除外区的陶器女巫回墓。

**终场：I：P百变莱娜 + 魔女术代理师傅 + 学童组合 + 服装女巫 + 恩底弥翁的侍女 杰妮 + 超魔导龙骑士
+ 反击陷阱「歪曲」（盖）+ 永续魔法「小巷」（表侧）。**

**对方回合**：杰妮 除外自己 → 特召 **玻璃女巫** 当阻坑，同时触发代理师傅回收墓地的慶典；
学童组合 展示手卡的慶典 → 复制它"破坏对方卡片"的效果。

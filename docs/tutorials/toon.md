# 卡通 教程摘要（用户原文的机制/线路摘录）

> 收录：2026-10-05。原文目录：核心循环（暗黑兔反复发动场地）/ 终场 / 暗黑兔·漫画猫·场地·书签 四条单卡 combo。

## 一、核心循环：用「滑稽暗黑兔」反复发动「完美世界 卡通世界」

* **暗黑兔③**（1 回合 1 次，自己主要阶段）：从卡组选 1 张「卡通」场地·永续魔法**加入手卡或在自己场上表侧放置**
  → 只用来调度「完美世界 卡通世界」（其他本家场地·永续都不赚卡）。
* **场地②**：1 回合可以**使用最多 3 次**（"1 回合 1 次，自己主要阶段 → 把 1 张「卡通」卡或者有那卡名记述的卡
  从卡组加入手卡"）。注意：**同一张场地在场时每回合只能发 1 次**，要拿"最多 3 次"的收益必须
  **用新场地替换已经发过②的旧场地**。
* **暗黑兔③ 没有卡名一回合一次** → 只要**刷新它的状态**就能再发一次（再拿一张新场地）→ 再发场地②。
* **场地③**＝刷新手段：其他卡发动的效果适用之际，把自己场上 1 只卡通怪兽**直到那个效果处理后除外**
  （同一回合内这个卡名的这个效果不能除外原本卡名相同的怪兽）。
  → 所以循环是：暗黑兔③ 贴场地 → 场地② 检索 → 用某个效果（如暗眼的手卡怪效/看透心灵之眼②）触发场地③ 刷新暗黑兔
  → 暗黑兔③ 再贴一张新场地 → 场地② 再检索 …… 最多 3 轮。
* **卡通目录**检索「青眼卡通龙」；**青眼卡通究极龙**＝把场上 2 只暗黑兔 + 手卡青眼卡通龙**回到卡组**特召
  （究极龙② 也是"没有卡名一回合一次"的墓地回收 → 可被场地③ 刷新做 2 次：先回收目录、再回收暗眼）。
  ⚠「邪魔箱」「滑稽暗黑兔」「漫画猫」**都没有「卡通」字段**（只有"有「卡通世界」卡名记述"）→ 不能被卡通目录检索。
* **漫画猫②**（自己·对方主要阶段）：解放自己场上 1 只怪兽 → 从手卡·卡组无视召唤条件特召 1 只本家怪兽；
  有「卡通世界」时**也能从对方场上选解放的怪兽**（⚠ 解放是**效果**、先发动后解放 → 不能解放全抗怪）。
* **暗黑兔①**：这张卡召唤·特殊召唤时适用，这个回合自己在通常召唤外**追加 1 次**能把"有「卡通世界」卡名记述的怪兽"召唤。

## 二、终场（暗黑兔单卡打完）

**青眼卡通究极龙 + 漫画猫 + 邪魔箱 + 场地「完美世界 卡通世界」+ 反击陷阱「卡通恐怖/卡通叙述者」
+ 永续陷阱「看透心灵之眼」。**

阻坑清单（原文口径）：漫画猫的解放（1 次）＋ 邪魔箱③ 的墓地干扰（**没有卡名一回合一次**、可被场地刷新做 2 次）
＋ 看透心灵之眼② 的宣言无效 ＋ 卡通恐怖 的三色反击康。另外**场地③ 本身就是躲解场卡的手段**
（例：对手「禁忌的一滴」→ 用场地③ 把漫画猫除外，逼对手只能选究极龙和邪魔箱）。

**判定细节**：
* **邪魔箱③**：自己·对方回合 1 次，以自己或对方墓地 1 张卡为对象 → 那张卡回到卡组最下面（展开时回收自己用完的场地，
  也可回收对手墓地的卡当干扰）。
* **看透心灵之眼**：① 只要自己场上或墓地有「卡通」卡，**对方把手卡全部持续公开**、自己随时可以确认对方里侧卡；
  ② 自己场上·墓地有卡通怪兽以及「卡通」魔法卡时，宣言 1 个同一连锁上没有把效果发动的卡名 → 直到回合结束
  同名卡发动的效果无效化。⚠ **康不了能二速发动的速攻魔法**（C1 开②，对手能 C2 发动那张速攻）→ 那种交给卡通恐怖。
* **究极龙③**：自己的卡通怪兽被攻击的伤害计算时才能发动 → 那只怪兽直到伤害步骤结束时除外
  → 攻击落空、**且不产生卷回**（卷回只发生在攻击宣言后、伤害计算前）。
* 「看透心灵之眼」是暗眼幻想师① 从手卡丢弃自身时**最先调度**的（先攻防手坑）。

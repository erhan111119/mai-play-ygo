## 6.7 死牌表：**十副牌一张死牌都没有**（`tools/card_vitality.py`）

口径：只读 s4/s5/s81（270+450+180 局，**180 局/副**）——s1/s2 录在 `duel/recorder.py` 分座位之前（双方混记），

`left_style`/`right_style` 选 `card_usage` / `card_usage_opponent` 那一列。

结论：**十副牌的主卡，每一张都在对局里被用过**（召唤/特殊召唤/反转召唤/发动效果/盖放至少一次）。

这条结论同时否掉了此前几个"脚本漏登记"的假设：刻魔的**场地「天魔之声选器」73.9% 局用上**（3 张、
1.3 事件/局）、「锻冶师」36%（1 张、1.1/局）、「红泪之魔 落泪」42%（1 张、1.8/局）、

也就是说**没有"执行器不会用某张主卡"的黑洞**，剩下的差距要么是抽不到（1 张件的抽到率天花板），
要么是链太长。

顺带把**手坑使用率对了一遍算术**：1 张件在一局里（起手 5 + 几回合抽牌，约 7~8 张）被看到 ≈ 19%，
实测 1 张的手坑是 **9%~33%**（灰流丽 18~31%、增殖的G 13~33%、欢聚友伴 10~14%），2 张的灰流丽 45%
——和"抽到就交"的期望一致 ✔，**不是"手坑被脚本扣在手里"**。（最低的那个 0.6% 是卡通「青眼卡通龙」：
它的用法是给「青眼卡通究极龙」当**融合素材洗回卡组**，不是摆上场，所以台账里没有事件是对的。）

  「刻魔融合怪兽(落泪之日) + 一只融合/连接怪」的素材同时在场/在墓。

## 6.9 刻魔「狮鹫当妥协场」A/B：**机制生效，胜负没提升 ⇒ 默认保持"链优先"**（2026-10-07）

代码里原话：「拦它是对的（链优先），但'链断了的局里要不要用狮鹫当妥协场（2500 + 锁）'
**从来没量过**」。开关 `KZ_GRYPHON_ALWAYS=1` 就是为这一问留的。

**第一步先验机制**（对空白 20 局，`temp/train/blankR-100-gryphon.log` vs `blankR-100.log`）：

| 读数 | 默认 | `KZ_GRYPHON_ALWAYS=1` |
|---|---|---|
| 狮鹫落位 | **0 次** | **7 次** ✔（干预真的发生了） |
| 平均动作 / 特召 / 效果 | 32.7 / 9.3 / 16.5 | 38.6 / 11.4 / 19.3 |
| 大聖棺 / 哥布林 / 阎摩 | 5 / 1 / 1 | 3 / 1 / 1（链上件没被吃掉多少） |

**第二步才读胜负**（`bash temp/ab_gryphon.sh`，同协议双腿各 180 局、刻魔恒在左、9 个对手 × 20 局）：

| 腿 | 胜率 | 95% 区间 |
|---|---|---|
| 默认（链优先） | **49/180 = 27.2%** | 21%~34% |
| `KZ_GRYPHON_ALWAYS=1`（妥协场） | **42/180 = 23.3%** | 18%~30% |

两臂差 3.9 个点、区间大幅重叠 ⇒ **不显著**；逐对手的摆幅（俱舍 5%→25%、虫惑魔 55%→20%）
正是 20 局/格的噪声形状。⇒ **默认不变**（狮鹫仍然只在"阎摩已站场"时出），开关留着。

## 6.11 购物单：该加 / 该减候选（**s8，720 局 / 144 局一副，其中 72~78 局读得到手牌**）

量具：`python tools/vitality_table.py --arenas s8 --verbose`。
门槛：**该加**＝只带 1~2 张、转化（到手→用上）≥ 80%、但到手率 ≤ 35%；
**该减**＝到手率 ≥ 50% 且转化 ≤ 40%；**多余拷贝**＝≥3 张而使用局数 ≤ 25%；
三类都要求"到手过 ≥ 5 局"（否则比率全是噪声，还会把"这副牌根本不靠抽它"的卡算进来）。

s8 的成绩单（顺便是**第十轮基线**，与九轮合计一致：珠泪 83 / 俱舍 78 / 卡通 68 / 升辉月 59 /
魔女术 48 / 耀圣 39 / 虫惑魔 38 / 杀调 34 / 闪刀 31 / 刻魔 22 %）。

### 该减（**只有三条，而且都很弱**——按卡文核过之后更弱）

| 牌 | 卡 | 读数（s8） | 核过卡文/数据之后的判断 |
|---|---|---|---|
| 卡通 | 青眼卡通龙（1 张） | 到手 88%、转化 **2%** | **已知误报**：它是「青眼卡通究极龙」的**融合素材**（从手/场/墓洗回卡组），台账里不会有事件 ⇒ **不删** |
| 杀调 | PSY骨架装备·δ（**3 张**） | 到手 44%、转化 32% | 先核卡文：δ 的①要「自己场上没有怪兽 + 对手发动**魔法**」两个条件，而驱动者可以从**手卡·卡组·墓地**拉（所以**不是**"缺配套"）。实测 48 局：δ 到手 22 局只用上 6 局（27%），γ 也只有 33% ⇒ 两个 PSY 件的转化都低；**但"到手没用上"的 16 局胜率 50%，比这副牌整体（40%）还高** ⇒ "它在拖后腿"**没有被数据支持**。保持候选，等 sh9 的整轮 A/B（δ 3→2、同调超车 1→2） |
| 耀圣 | 三战之才（**2 张**） | 到手 53%、转化 38% | 卡文：要在**自己主要阶段**且"对手这回合发过怪兽效果"才能用。同一张卡在杀调里转化 65%、在耀圣里 36% ⇒ 一半是样本小。同样只算候选 |

（杀调的 δ 同时落进"多余拷贝"：3 张、使用局数只有 17%。）

**这张表的正确读法**（别越界）：

* 转化率量的是**卡位效率**（"抽到它有没有用上"），**不是"它在不在拖后腿"**——
  后者要看"到手没用上"那些局的胜率。按上面 δ 的例子，那个胜率**不比整体低**，
  所以"该减"最多只能算"这个卡位可能放得更有价值"，不能算"这张卡在害我们"。
* 反过来看"用上了的胜率"会掉进另一个坑：s8 里杀调「同调超车」用上 15 局胜率只有 27%（整体 40%）、
  「G」用上 7 局 57%——因为"要用到手坑/续航件"本身就意味着**对手正在做事、局在变长**（混杂）。
  **别拿使用率当收益**。
* **"每局到手张数/卡种"也不能用来比副牌强弱**（2026-10-07 试过）：s8 里最强的那副最低——珠泪中位
  10 张 / 8 种，而卡通 15 张 / 10 种、升辉月 15 张 / 12 种。这个数测的是**局长**（局短＝抽得少），
  不是牌强度；跨副牌比它只会把"赢太快"读成"手牌差"。

### 该加（各副牌"到手就用"的 1 张件，挑前几条）

| 牌 | 候选（到手率 → 转化） |
|---|---|
| 升辉月 | 愚蠢的副葬（33%→96%）、抽卡面包（35%→89%） |
| 魔女术 | 绘画女巫（30%→95%）、陶器女巫（21%→80%） |
| 卡通 | 三战之号（24%→88%） |
| 杀调 | 同调超车（31%→96%） |
| 闪刀 | 灰流丽/G/增援/零衣/露世/三战之才（25~33%→84~100%，共 7 条） |
| 耀圣 | G（18%→92%）、狂想曲（24%→83%）、灰流丽（23%→82%） |
| 刻魔 | **锻冶师（19%→100%）**、詠聖（31%→87%）、倒水（24%→89%）、不调和（22%→81%）、指名者（28%→81%） |
| 俱舍 | 金满而谦虚之壶（13%→100%）、星球改造（17%→100%）、黄金柜（17%→92%） |
| 珠泪 | 劈穿壹世坏的弦声（27%→100%） |

**读法（三条，别当"十个结论"）**：

1. **"该加"只对"你希望抽到"的卡成立**。像珠泪「劈穿壹世坏的弦声」那样"用（53%）远大于到手（27%）"
   的件，说明它主要是**从卡组/墓地直接出场**的，多一张只提高了"抽到手"的概率，不一定是好事。
   （表里"用"这一列就是给这个判断用的。）
2. **转化率的分母是"到手"、分子是"又到手又用上"**——同一局里从卡组/墓地直接特召的卡
   会被记进用卡台账但没进过手牌，所以**不能**拿"总使用局数 ÷ 到手局数"（那会算出 >100%，
   实测过 104%~400%）。口径细节见 `tools/card_vitality.py` 的 `load_usage`。
3. **每一条都要先做成影子卡组再跑同协议两臂**（§6.9/§6.10 的方法）。已经量过两次"看起来该动"的
   改动（刻魔狮鹫妥协场、刻魔引擎加厚），**都是机制生效、胜负不显著**——别跳过这一步直接改线上 `.ydk`。

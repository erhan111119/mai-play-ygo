# 验收标准（按社区公认口径，2026-10-04 检索后落地）

> **2026-10-07 补注（当前工具链）**：这份文档的*规格*仍然有效，但下面"怎么跑"那一节已经过时——
> 现在常用的四条命令是：
> ```bash
> bash temp/blank_leg.sh 88 93 …           # 对空白 20 局/副（verbose）→ temp/train/blankR-<编号>.log
> bash temp/sweep.sh 5 3 6                 # 十副牌两两对打 3 轮/组（54 局/副），落 rounds.db 的 arena=s5
> bash temp/wall_leg.sh 101                # 对手坑墙 20 局（口径②"有阻抗→妥协场"）
> python tools/first_turn_accept.py --log <日志> --deck-id <编号> --turn-limit 2 --monster <件名>  # 首回合验收件（可信口径）
> ```
> 规格现在由 `tools/max_board.py` 的 `DECKS`（**已覆盖十副牌**）与各执行器注释承载；
> 十副牌的实测汇总见 **`docs/deck-audit.md`**。⚠ `first_turn_accept.py` 的落位口径比
> `max_board.py` 的回放口径可信（后者实测会漏件）。

> 用户口径：**每副牌都要能做出终端与"最大场"**；最大场 = **终端怪兽数 + 这一回合场上能对
> 对面展开进行多少次阻抗**；并且**不损耗资源、不自己炸自己、能打断对面**。
> 下面每副牌的"公认终端/合格线"来自社区资料（B 站教程、日文 wiki、MC 高分专访），
> 链接列在每节末尾。判定一律用 `tools/plan_accept.py`（逐局取"我方第 1 回合结束"的场面，
> 窗口含结束阶段；`--interrupt` 数对面回合里我方实际发动效果的次数）。

## 计量方法（三张表，缺一不可）

1. **终端件（`--monster/--spell/--grave`）**：场上/墓地有哪些点名的件；
2. **潜在阻抗次数**：场上"能在对方回合打断"的件数（每张卡的具体效果见各节标注）；
3. **实际拦截**：`--interrupt` 在**真对手**局里数我方在对面回合发动效果的次数
   （对空白对手恒为 0，没得拦）。
   另外两条红线用日志人工核：**不自己炸自己**（我方效果炸/送掉我方关键件）、
   **不损耗资源**（把终场件当融合/连接素材喂掉、壶除外自己额外卡组等）。

## 一、魔女术 / Witchcrafter（#93）

* **公认满编场（6 怪 + 2 魔陷）**：I:P百变莱娜、魔女术代理师傅、魔女术学童组合、魔女术工匠·服装女巫、
  恩底弥翁的侍女 杰妮、超魔导龙骑士-真红眼龙骑士 ＋ 反击陷阱「魔女术的歪曲」（盖）＋ 永续魔法
  「魔女术的小巷」（表侧）；墓地留「魔女术的怠工」（EP 回手当 cost）。
* **合格线（吃坑妥协版）**：**代理师傅 + 学童组合 + 服装女巫 + 玻璃女巫 + 歪曲（盖）**，
  玻璃女巫一般由杰妮在对方回合从卡组拉出。
* **干扰件**（按"能实际发动的次数"数，公认 6～7 段）：超魔导龙骑士（1 次三色无效）＋ 歪曲（三色反击）
  ＋ 服装女巫（丢 1 魔法炸 1 表侧）＋ 代理师傅（炸卡/拉人/回收三选一的诱发）＋ 玻璃女巫（丢魔法 →
  对方全场表侧怪兽效果无效）＋ 学童组合（复制手卡速攻）＋ I:P（对方回合加速连接）。
* **资源自检**：玻璃女巫/服装女巫/代理师傅每次都要丢手牌魔法，合格场要能靠「小巷/怠工/创造」的
  EP 回收 + 代理师傅回收凑出 ~3 张 cost，否则实际挡数打折。
* **分水岭**：三只融合（大魔女/学童组合/代理师傅）出了几只。
* 来源：[B 站 202605 魔女术教程](https://www.bilibili.com/read/cv48385887)、
  [ygocdb 魔女术全卡文本](https://ygocdb.com/?search=魔女术)、

## 二、卡通 / Toon（#94）

* **公认终端（单卡展开成品）**：青眼卡通究极龙、漫画猫、邪魔箱 ＋ 场地「完美世界 卡通世界」（表侧）
  ＋ 反击陷阱「卡通恐怖」（盖）＋ 永续陷阱「看透心灵之眼」（表）。
* **合格线（社区四件套）**：**完美世界卡通世界 + 漫画猫 + 卡通恐怖 + 看透心灵之眼**，
  凑齐后不必强行多做，"3 个阻抗"往往就够赢。
* **干扰件（公认"5 康"）**：漫画猫（解放 1 只，场上有卡通世界时可解放对方怪兽）＋ 邪魔箱③（双方回合
  各 1 次墓地干扰，可被场地刷新做 2 次）＋ 看透心灵之眼②（宣言卡名无效）＋ 卡通恐怖（三色反击）；
  另有究极龙①（全场卡通直击）与场地③（保护/刷新）。
* **核心循环**：滑稽暗黑兔③ 反复表侧放置场地 → 场地② 每换一张新场地再检索 1 张本家卡
  （名义 1 回合 3 次）→ 场地③ 把己方卡通怪兽除外再回场刷新其 1 回合 1 次效果。

## 三、闪刀姬 / Sky Striker（#96）

* **合格线（数值化，最好测）**：回合结束时 **墓地「闪刀」魔法 ≥3 张（三魔）** ＋ **额外怪兽区有
  零露或雫空** ＋ **墓地有「双纽闪门」** ＋（有则）**抓锚在手**；干扰段数 ≥3。
  ⚠ 三魔是硬指标：凑不出三魔时抓锚只有无效、亚式收益下降，视为未达标；主怪兽区不能有怪
  （否则闪刀魔法发不了）。
* **干扰件**：抓锚（无效 1 只，三魔时可夺控制权）＋ 零露②（双方回合解放自身 → SS 零衣+露世并炸 1 张）
  ＋ 双纽闪门②（墓地加速连接 → 阿泽莉亚炸 1 / 泽克除外 1）＋ 泽克 / 阿泽莉亚 / 烈火再燃 等。
* **标准展开线（竞技默认）**：开交闪 → NS 零衣 → ①变火刀回收交闪 → 再开交闪 → 变水刀（雫空）
  EP 检索连刀 → 连刀在 EMZ SS 零露 → 零露①找亚式（做阻抗）或交闪（保续航）。
* **注意**：闪刀**没有大康场**，合格标准是"多段小干扰 + 资源循环"，不要按"背步骤"验收，
  要按"终场要素 + 三魔 + 干扰段数"。
* 来源：[闪刀新卡杂谈（两条先手线 + 三魔）](https://www.bilibili.com/read/cv41294277)、
  [萌卡竞技环境闪刀心得](https://www.bilibili.com/read/cv42401577)、
  [Master Duel Meta Sky Striker 指南](https://www.masterduelmeta.com/guides/sky-striker-spook/)

## 四、杀手级调整曲 / Kewl Tune（#95）

* **公认合格先手**：**锁缚龙（核心三色康）1 康 ＋ 重混/响度战争 1 个加速干扰 ＋ 场地或盖速攻的续航**。
* **上限场**：锁缚龙 + 鲜花女男爵 + B2B + 本家反击 ≈ 3 次三色康，外加下级送墓效果（炸怪/炸魔陷/弹卡/看手）。
* **干扰件**：锁缚龙（无效连锁中第 1/2 个效果）＋ B2B（对方怪兽效果发动时加速出锁缚龙）＋
  重混（对方回合解放自身 → 回收 + 特召 + 立刻同调）＋ 响度战争（复制墓地本家的送墓效果）＋
  红印鉴（二速无效 1 张表侧卡）＋ 鲜花女男爵/白维萨斯（系统外，标配）。
* **骨架共识**：3 星 + 1 星 = Lv4 音轨制作人（检索 1 张本家）→ 制作人 + 3 星 + 手牌 1 星 = Lv8 白维萨斯 →
  8+2 = Lv10 B2B → 对方回合 B2B 加速出锁缚龙。**"这卡组没有特别固定的 CB"**（第 28 名专访原话），
  判定按"康的条数"而不是步骤。

## 五、升辉月 / 盈彩月夜（#88）

* **合格线（最低限构え）**：**「一掷乾坤」站在额外怪兽区**（只有额外区才有效果：不受其他效果影响 +
  把对方"从卡组加手"改成自己抽 1 + 双方回合拔 1 素材抽 1）＋ **「未眠之城」在场**。
* **满编线**：再加 **盖「辉煌」** 与 **手里留「菈碧」**（对方回合二速超量出 Rank7）。
* **本家没有检索（只能抽）**，所以**不要按固定步骤验收**，只看"抽牌链结束后三件套是否达成"。
* 干扰件：一掷乾坤（EMZ）＋ 千金大獎（拔素材把对手等量卡回卡组底）＋ 菈碧（对方回合加速超量）＋
  辉煌（盖放的陷阱特召本家超量并入素材）＋ 手牌的水属性本家（次 G 式搜抽压制）。
